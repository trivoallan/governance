# Proposal

## Why

ADR-0017 rules `agent.host: claude-code`, yet `.claude/` is untracked (#40).
There is no `marketplace/.claude-plugin/marketplace.json`, no
`.claude/settings.json` (so `governance-check ADR-0017` fails), and the
OpenSpec skills and commands this repository is worked with exist only as
untracked files in the main checkout: no worktree has them, and nobody
reviewed them. What keeps `.claude/worktrees/` and
`.claude/settings.local.json` out of git today is the maintainer's global
gitignore and `.git/info/exclude`, not the repository.

## What Changes

- A repository marketplace, `marketplace/.claude-plugin/marketplace.json`,
  with a name of its own and every entry pinned to a full commit `sha`.
- A committed `.claude/settings.json` that declares that marketplace through
  `extraKnownMarketplaces` (a `directory` source, `./marketplace`) and
  turns its plugins on through `enabledPlugins`. Nothing else.
- The twelve OpenSpec skills (`.claude/skills/openspec-*/`) and twelve
  commands (`.claude/commands/opsx/`), generated by OpenSpec 1.13.1,
  reviewed (including `allowed-tools: Bash(openspec:*)`) and committed as
  vendored skills (ADR-0017 rule 3).
- `.gitignore` ignores `.claude/worktrees/` and `.claude/settings.local.json`.
- The README tells a contributor the one install command per plugin.

Out of scope: the personal permissions in `settings.local.json`;
`strictKnownMarketplaces` (managed setting); a check reading the
marketplace (ADR-0017 leaves it to review).

## Capabilities

### New Capabilities

- `repo-tooling`: how this repository carries out the ADRs it rules for
  itself; here, its Claude Code project configuration.

### Modified Capabilities

None.

## Impact

- New files: `marketplace/.claude-plugin/marketplace.json`,
  `.claude/settings.json`, 12 `SKILL.md` files, 12 command files.
- `.gitignore`: two lines. `README.md`: a short note.
- `marketplace/` is not in `package.json` `files`, so the npm package is
  unchanged.
- The main checkout holds the same paths untracked: they must be removed
  there before it pulls the merge, or git refuses to overwrite them.
- Which plugins the marketplace lists is the maintainer's choice, each
  admitted by a person as ADR-0020 asks.
